# Project business vision statement
**Project Lifecycle Phase:**
Phase1 (Data prototyping & anomaly validation)

# Strategic core mission 
To empower retail stakeholders with a unified, data driven BI ecosystem that transforms raw transactional data into strategic insights.

# Core problem statement addressed
1. Over dependency: Massive structural dependency on a single category (Electronics genrate 88% of sales), masking operational drag and vulnerabilities in smaller categories.
2. Operational inefficiency: Grocery category, which exhibits a high return rate(61% relative to the electronics benchmark) while contributing a microscopic 0.36% to net profit margin.
3. Siloed performance tracking: Lack of consolidated demographic and geographic cross-filtering.

# Tech stack & Architecture validation

1. ETL Layer: Power Query data ingestion engines
2. Semantic Layer: Star schema Relational data modelling
3. visualisation layer: Excel Power pivot analytics enviornment (targeted for migration to enterprise - scale SQL & Power BI in product increment Phase2)
